## 项目简介

**TaskSync** 是一个面向小团队的 **AI 任务协同规划智能体**——输入团队目标和成员信息，AI 自动拆解任务、分配责任、排定优先级与时间线，并在执行过程中根据进度和突发情况动态调整计划。

**核心定位**：命中「智能协同办公」赛道，利用 MoMA 平台的多模型路由与工作流编排能力，实现低成本、高智能的团队任务管理。

| 方向 | 一句话 | 状态 |
|---|---|---|
| **团队任务协同规划 TaskSync** | 输入团队目标→AI拆解任务、分配责任、动态调整计划 | ✅ 已确定方向（待验证） |
| 校园健康饮食协同 DietSync（备选） | 食堂↔后勤↔学生三方饮食健康协同平台 | 💤 冻结备选 |

## 贯穿方向的决策标准

**硬核部分必须是「可选的」，不能是「承重的」。**
项目最难的部分（动态重规划）如果失败，静态任务拆解+分配仍然成立、仍然可交付。

**完成度高的中等作品，永远赢过完成度低的高远作品。**
